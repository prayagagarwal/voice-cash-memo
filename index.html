      Items the app knows

        You don’t need to set up items. Whatever name is said goes on the bill as said, and is remembered when the bill is saved, along with its rate. If the same item gets two names (say Bengali and Hindi), tap the line and pick the known item once. The app links the names from then on.

        How to speak and correct
        • Mix languages freely, even inside one sentence: “sona moong দু কেজি 145 rupaye”. Each word is matched by how it sounds, whatever script the mic writes it in. Keep the mic language on বাংলা; Hindi and English words still work. If one language keeps going wrong, try the हिन्दी chip for a day and compare.
        • Voice needs mobile data (it uses Google’s free speech recognition). Without internet, type the items in the box.
        • No typing needed. Tap the mic, speak, tap again. The app reads each line back aloud.
        • Spoken commands: “customer Gupta”, “total kitna” / “মোট কত”, “bill padho” / “বিল পড়ো”, “save” / “বিল শেষ” / “ho gaya”, “naya bill” / “নতুন বিল”.
        • Answer a price alarm by saying the correct rate (“nahi nahi 145”), or “thik hai” / “ঠিক আছে” if the rate is right.
        • Answer “which one?” by saying it: “bhanga”, “sona”.
        • Item, quantity, rate in any order: “sona moong do kilo 145”, “সোনা মুগ দু কেজি ১৪৫ টাকা”.
        • Several items at once: join with “aur”, “আর” or “and”.
        • Change a rate: “sona moong 140” or “sona moong 140 kar do”. The same line updates.
        • Fix the last thing said: “nahi nahi 142”, “না না ১৪২”.
        • Add more of an item: “aro ek kilo sona moong”, “add 2 kilo lal badam”.
        • Remove: “lal badam hatao”, “লাল বাদাম বাদ দাও”.
        • Fractions: aadha / আধা, dedh / দেড়, dhai / আড়াই, sawa, paune, ek pao.
        • Price alarm: if a rate is far from that item’s usual rate over the last 7 days, the phone beeps, the line turns red, and the bill can’t be saved until someone checks it.
